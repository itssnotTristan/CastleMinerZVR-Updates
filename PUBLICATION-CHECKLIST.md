# Update publication checklist

Before publishing any update:

1. Confirm the version, platform and compatibility information match the actual tested build.
2. Review every public file. Exclude original game assets, complete private APKs, signing keys, credentials, personal worlds and private device logs.
3. Confirm an asset-free patch can be applied using the documented prerequisites. Do not promise one-click installation until verified.
4. Verify the artifact's file size and SHA-256 after upload, and test the download without GitHub authentication.
5. Explain known limitations and required build or installation steps in the release notes.
6. Publish the update feed only after its approved release and download are available. Never publish placeholders as a newer installable update.
7. Keep the exact credit: CastleMiner Z VR mod by ItssnotTristan.
